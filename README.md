# Permissible or Misconduct? NYPD Pepper-Spray Allegations

## Overview

This DSC 106 project presents two opposing perspectives on the proposition: **“NYPD pepper-spray allegations were usually ruled permissible.”**

Using the same dataset, we explore how pooling years, selecting a recent period, and emphasizing different outcomes can change the impression a visualization creates.

## Dataset

We use ProPublica’s July 2020 release of New York City Civilian Complaint Review Board (CCRB) records. Our analysis focuses on **324 allegations labeled “Pepper spray,” received between 1999 and 2019**.

The release contains selected closed, investigated cases and does not represent all NYPD complaints or all uses of pepper spray. Each row represents an allegation, not necessarily a unique complaint.

## What We Did

- Combined the substantiated disposition subcategories.
- Calculated overall disposition rates and rates by received-year period.
- Created a supporting visualization emphasizing the historical exoneration majority.
- Created an opposing visualization emphasizing recent substantiated findings.
- Evaluated how time selection, visual hierarchy, and wording influence interpretation.

**Exonerated** means the conduct occurred but was permitted under NYPD rules. It does not mean the complaint was false.
